# AMM 参数建议

整理：Haolin Liu · 2026-10-29  
用途：团队确认合约、前端与金融分析的统一参数。本文为建议稿，尚未修改模型或部署合约；数值是实验起点，并非已验证的最优参数。

## 1. Trading fee 与分账

保留 0.30% / 0.50% 两档。下表均为交易输入金额的百分比。

| 档位 | LP 留存 | Treasury 可用收入 | Bonus 奖励池 | 总手续费 |
|---|---:|---:|---:|---:|
| 基础档 | 0.25% | 0.04% | 0.01% | 0.30% |
| 高费率档 | 0.45% | 0.04% | 0.01% | 0.50% |

- LP 份额留在池内储备，按 LP token 份额归属。
- 协议份额合计仍为 0.05%，离开 LP 储备，再按 80% treasury / 20% bonus 分账；bonus 不重复收取。
- 按输入币种收费：USDX 输入产生 USDX 收入，WETH 输入产生 WETH 收入。
- 例：基础档输入 1,000 USDX，LP 留存 2.5、treasury 获得 0.4、bonus 获得 0.1 USDX。

理由：保留现有报价公式与 LP 费率，并为会员奖励提供实际资金来源。

运营盈亏平衡应按可用收入 0.04% 计算，未计获客成本：

| 月运营成本 | 所需月成交量 |
|---|---:|
| $50 | $125,000 |
| $100 | $250,000 |
| $200 | $500,000 |

以上为美元等值设计测算；Sepolia 收入是测试资产，WETH 收入的美元价值还取决于计价时点。

## 2. Membership 与 bonus

以首次注资后的 LP 总供应量为 S₀，部署时固定门槛。L 为用户在奖励合约中质押的 LP token 数量。

| 等级 | 质押门槛 | Bonus 权重倍数 |
|---|---|---:|
| Basic | 0 < L < 1% × S₀ | 1.00× |
| Silver | 1% × S₀ ≤ L < 5% × S₀ | 1.10× |
| Gold | L ≥ 5% × S₀ | 1.25× |

- 未质押者不参与 bonus，但其基础 LP 手续费权益不变。
- 倍数只作用于 bonus，不改变基础 LP 手续费或赎回份额。
- 每 7 天一期，以时间累计权重分配本期实际收到的奖励：

```text
用户权重 wᵢ = 本期内 ∫ [质押 LP 数量 Lᵢ(t) × 当时等级倍数 mᵢ(t)] dt
用户奖励 Rᵢ = 本期奖励总额 B × wᵢ / Σwⱼ
```

各奖励币种分别结算；本期无质押者时奖励滚存。1.25× 是分配权重，不是保证收益率。

理由：门槛随初始池规模确定，避免依赖任意 LP token 面额；温和倍数控制大额用户的额外优势，时间权重避免仅凭期末瞬时余额分配奖励。

该功能需要新增 LP 质押及奖励记账逻辑，现有模型尚未包含。

## 3. Dynamic fee

参考价格采用池内 30 分钟 TWAP；spot 使用本笔交易执行前的 USDX/WETH 储备比率。

```text
d = abs(交易前 spot / 30 分钟 TWAP - 1)
d ≤ 1%：总费率 0.30%
d > 1%：总费率 0.50%
```

- 只分两档，每笔执行前确定费率。
- 默认触发阈值为 1%；分析中比较 0.5%、1%、2%。
- 阈值与费率建议部署时固定；实验模式可调整假设。

理由：与现有模型一致，便于报价、合约执行和对账。当前结果不足以证明某个阈值最优；交易前判定可能无法对第一笔推动价格的交易收取高费率，报告中应说明。

## 4. Oracle / TWAP

| 项目 | 参数或行为 |
|---|---|
| TWAP 窗口 | 1,800 秒（30 分钟） |
| TWAP 未完成预热 | 使用 0.30% 基础档，前端显示预热中 |
| Chainlink 最大数据年龄 | 5,400 秒（90 分钟） |
| 价格非正、更新时间为 0、未来时间或数据超龄 | 阻止 swap，保留 LP 退出 |
| Chainlink 与池价偏离 | 展示偏离及套利提示，不另设偏离熔断 |

池内 TWAP 用于动态费率；Chainlink ETH/USD 用于外部参考和有效性检查。TWAP 预热期间仍需通过 Chainlink 有效性检查。

读取 `latestRoundData()` 的价格和 `updatedAt`，按 `decimals()` 归一化。90 分钟是项目允许的数据年龄，不是 Chainlink 保证的更新周期；部署前应核对所选 feed 的更新机制。

接口参考：[Chainlink — Using Data Feeds on EVM Chains](https://docs.chain.link/data-feeds/using-data-feeds)。

## 5. Initial liquidity

### Sepolia 实际部署

```text
WETH 初始投入 = 0.01 WETH
USDX 初始投入 = 0.01 × P₀
P₀ = 初始化时通过有效性检查的 Chainlink ETH/USD 价格
假设 1 USDX = 1 USD
```

例如，仅作演示，若 P₀ = $2,500，则投入 0.01 WETH + 25 USDX，名义 TVL 为 $50。这种小池中约 0.25 USDX 的订单就接近 1% 曲线冲击，演示订单应按储备比例设置。

理由：减少测试 ETH 用量，同时让初始池价与外部参考一致。若测试资金不足，应等比例缩小两侧投入。

### 金融分析参考场景

继续使用 20 WETH + 50,000 USDX、起始价格 $2,500、TVL $100,000。分析池与实际部署池必须分别标注；链上对账使用真实交易前储备。

## 6. Simulator 参数

| 参数 | 默认值 | 用户可调整 |
|---|---|---|
| 池子 TVL | $100,000；预设 $20k / $100k / $500k | 是 |
| 初始价格 | 合成情景 $2,500；历史回测用首个价格 | 合成情景可调 |
| Swap 金额 | 500 USDX | 是 |
| LP 投入 | $10,000 等值的配对资产 | 是 |
| 模拟期限 | 30 天 | 是 |
| 价格情景 | 平稳、震荡、上涨、下跌 | 是 |
| 零售成交量 | $5,000/天 | 是 |
| 零售交易笔数 | 20 笔/天 | 是 |
| DCA 本金 | $10,000 | 是 |
| DCA 间隔 | 24 小时；提供 72 / 168 小时选项 | 是 |
| Gas | Sepolia 现金成本 0；经济情景 $6/swap | 是 |
| 费率、分账、会员门槛、TWAP 窗口 | 本文建议参数 | 正式模式只读；实验模式可调 |

- DCA 从总预算中先预留 gas，再分配买入金额，避免负现金。
- 实验模式明确标注假设参数；真实交易前重新读取链上储备、规则和报价。
- Sepolia 的零现金成本不代表交易不消耗 gas 或测试 ETH。
