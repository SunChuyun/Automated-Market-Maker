# Contributing

Use a feature branch and a pull request in the shared team repository. Responsibilities, local setup, synchronization commands, and review expectations are documented in the [team guide](team-guide/README.md).

Run the checks relevant to your change, describe how you verified it, and request another team member's review before merging to `main`. Keep all repository content in English.

For contributions to the underlying Scaffold-ETH framework itself, refer to the [upstream contributing guide](https://github.com/scaffold-eth/scaffold-eth-2/blob/main/CONTRIBUTING.md).
